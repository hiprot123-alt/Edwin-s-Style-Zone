EDWIN'S STYLE ZONE — REFERENCE-INSPIRED FRONTEND V2

This is an original design inspired by the broad structure of the reference salon website supplied by the client. It does not use Toni & Guy branding, logo or copy.

RUN LOCALLY
1. Extract the ZIP.
2. Open this folder in Visual Studio Code.
3. Open index.html in a browser, or use the Live Server extension.
4. Internet access is needed for Google Fonts and remote Unsplash images.

FEATURES
- Responsive desktop and mobile navigation
- Full-width hero with 3 image slides
- About section, rating/review metrics, image-led service cards
- Brand values, gallery, testimonial cards and appointment enquiry
- WhatsApp appointment request form

PLEASE VERIFY BEFORE CLIENT LAUNCH
- Phone number, location/address and all offered services with the salon owner.
- The supplied Google rating/review count is from the screenshots and may change.
- Review excerpts are adapted from screenshots supplied by the user. Confirm accuracy and obtain permission before republishing.
- The appointment form sends a WhatsApp enquiry only; it does not check live slot availability or confirm a booking.
- Images are externally hosted Unsplash images and are placeholders. Replace with salon-owned/licensed photos for final delivery.
- No prices or opening hours were provided, so none have been invented.
